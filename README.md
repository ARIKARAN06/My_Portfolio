# Arikaran Portfolio

Complete editable static website. Includes the smaller mouse-following glow, wide project carousel, running skills strip, theme toggle, and resume PDF. The rubber-band heading effect has been removed.

## Open
Extract the ZIP and open index.html in your browser. No installation or build is needed.

## Files
- index.html: website content and structure
- style.css: styling, layouts, animations
- motion.js: mouse glow and scroll effects
- carousel.js: project carousel and skills strip controls
- interactive.js: project filters and rotating title
- theme.js: light/dark mode
- Arikaran_Resume.pdf: resume

Keep all files together. Online fonts use fallback fonts when offline.
