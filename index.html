05 / ONGOING RESEARCH↗
FACULTY-SUPERVISED RESEARCHWeed detection.
Paddy fields.YOLO + CNN · Precision agriculture

Paddy Field Weed Detection

Developing a faculty-supervised computer vision project using YOLO and CNNs to identify and localize weeds in paddy fields, with the goal of supporting targeted herbicide application.

YOLOCNNComputer VisionOngoing Research
Explore the research +
  • Weed-species data collection: Gathering images of weeds found in paddy fields to build a dataset for model training.
  • YOLO-based localization: Developing detection methods to locate weeds within field images, supporting identification of areas that require treatment.
  • CNN-based image analysis: Exploring visual features that help distinguish weed species as part of the recognition workflow.
  • Targeted spraying: Aiming to use weed locations to guide herbicide application to specific affected areas instead of spraying the entire field.
  • Research evaluation: Future evaluation will need to assess detection accuracy and missed weeds before testing the approach in field conditions.
  • Intended agricultural benefit: Seeking to reduce unnecessary herbicide use and support more resource-efficient weed management for farmers.

Dataset collection and model development are ongoing; field performance and chemical-use reduction have not yet been measured.
